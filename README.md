## Chromatic Aberration RGB Glitch Art Canvas

A real-time glitch art generator that applies chromatic aberration (RGB channel separation), scanlines, noise grain, and horizontal block displacement to procedurally generated abstract artwork. The base image uses seeded random geometry (circles, rectangles, triangles, neon lines) rendered on an HTML5 Canvas.

**Tech:** Vanilla JS, HTML5 Canvas (pixel-level ImageData manipulation), Tailwind CSS. **How to use:** Adjust the four sliders to control RGB shift (px), scanline intensity, noise grain, and glitch block count. Click Randomize to generate a new base image. Download PNG saves the current output at 600×400px.
